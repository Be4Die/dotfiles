# ADR 004: Скриншотер Flameshot + Grim на Wayland без диалогов выбора

> **Дата:** Сентябрь 2026 г.  
> **Статус:** Принято / Внедрено  
> **Затронутые хосты:** `desktop` (`cachyos-pc`), `laptop`  
> **Компоненты:** Flameshot, Grim, Hyprland, Slurp

---

## 1. Контекст и проблема
Пользователю требовался быстрый и удобный опыт снятия скриншотов с возможностью моментального выделения области экрана, рисования стрелок, текста и копирования в буфер обмена (подобно Lightshot).

При стандартных реализациях возникали проблемы:
1. **Satty:** требовал промежуточного выбора области через `slurp`, после чего открывалось отдельное тяжелое окно редактора с задержкой, дергались тайловые окна в Hyprland.
2. **Flameshot на Wayland:** по умолчанию вызывал системный диалог выбора монитора (Portal Picker Dialog), либо падал при работе с несколькими дисплеями с разной ориентацией (горизонтальный HDMI + вертикальный DVI на ПК).
3. **Иконка в трее:** висела неиспользуемой и создавала лишний визуальный шум в Waybar.

---

## 2. Принятое решение

1. **Отказ от Satty в пользу Flameshot GUI:**
   - Пакет `satty` удален из горячих клавиш.
   - Flameshot интегрирован с адаптером `grim` для бесшовного захвата всего виртуального экрана Wayland без вызова диалога выбора монитора.

2. **Оконные правила Hyprland:**
   - В [hypr/.config/hypr/hyprland.lua](file:///home/michael/dotfiles/hypr/.config/hypr/hyprland.lua) настроены специальные правила для оверлея Flameshot: плавающий режим (`floating`), отключение анимаций для моментального появления, растягивание на полный экран.

3. **Горячие клавиши:**
   - Клавиша `Print` и комбинация `Super + S` привязаны непосредственно к `flameshot gui`:
     ```lua
     hl.bind("", "Print", hl.dsp.exec_cmd("flameshot gui"))
     hl.bind("SUPER", "S", hl.dsp.exec_cmd("flameshot gui"))
     ```

4. **Очистка настроек:**
   - Трей отключен в `flameshot.ini` (`showTrayIcon=false`).
   - Удалены устаревшие параметры адаптеров.

---

## 3. Последствия и правила для агента
* Не возвращать `satty` или интерактивные пикеры экрана.
* При правках горячих клавиш сохранять `Super + S` и `Print` за `flameshot gui`.
